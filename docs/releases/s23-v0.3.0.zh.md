# GhostSam S23 0.3.0

正式 Release，版本 `0.3.0`（build 66），包名 `com.snothin.ghostsam.s23`。

## 更新

- 修复 root 后重新打开应用时首页状态回到初始值的问题。回到前台重新验证 su，
  检测失败后持续重试；模块加载记录按本次内核启动保存，不再依赖应用当时是否已获授权。
- 移除固件编号和完整内核字符串的精确匹配，继续检查机型、最低 SDK、KMI 和运行条件。
- 整合 GhostSam v0.2.4 与配套 Samsung KernelSU，保持官方 Manager 3.3.1 / UAPI 5。
- 重设计小幽灵图标：深墨绿底、薄荷白主体，支持自适应裁切和单色主题。
- 精简中英文 README，下载和使用信息集中在首页，详细维护记录保留在文档中。

## 支持与验证

- 国行 Galaxy S23 **SM-S9110**，Android 16 及后续版本，KMI **android13-5.15**。
- 用户已于 2026-11-10 反馈：One UI 8.5 / Android 16 / `S9110ZCS8FZJ1`
  上 build 65 的 root 和重开首页状态正常。本版沿用该运行逻辑，新增图标和发布版本信息。
- One UI 9 与其他 KMI 尚未验证；移除精确匹配不代表所有新内核都兼容。
- 本版发布前由 CI 从固定源码重建驱动和 ksud，执行单元测试、APK 版本与包名、
  载荷和签名检查，并核对上传附件的大小与 SHA-256 后公开发布。

## 安装

1. 下载附件 **GhostSam-S23.apk**，保留官方 **KernelSU Manager 3.3.1**。
2. 此包采用本次 CI 的 debug 签名。若与旧版签名冲突，先保存需要的设置和日志，
   卸载旧 GhostSam S23，再安装新版；卸载会清除应用自身的数据。
3. 如果手机当前已 root，在 KSU 的“超级用户”中重新授权 GhostSam S23 后返回应用，
   无需再次执行获取 root。首次使用或完整重启后，再执行临时 root 流程。
4. 首页显示“KernelSU 已启用”后可打开 KSU 使用软重启。
   完整重启后临时 root 失效；切换已加载驱动时也需完整重启。

附件包含 `GhostSam-S23.apk`、`BUILD-INFO.txt` 和 `SHA256SUMS`。
在下载目录执行 `sha256sum -c SHA256SUMS` 校验文件。
