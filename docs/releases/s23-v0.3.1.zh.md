# GhostSam S23 0.3.1

正式 Release，版本 `0.3.1`（build 67），包名 `com.snothin.ghostsam.s23`。

## 更新

- 修复发布任务重跑时重新设置 GitHub Latest 的问题。已公开版本完成源码、
  发布者和附件校验后直接结束，不再修改发布状态或 Latest。
- 首次发布草稿时按数字比较所有已发布的 S23 正式版本；较旧草稿可以发布，
  但不会覆盖更新版本的 Latest。发布任务串行执行，避免同时读取过期版本列表。
- 新增发布重跑、乱序草稿、多页版本列表、候选版和 API 失败等回归测试。
- 应用运行逻辑与 0.3.0 相同，保留首页 root 状态恢复和新版幽灵图标。

## 支持与验证

支持国行 Galaxy S23 **SM-S9110**，Android 16 及后续版本，KMI **android13-5.15**，
配合官方 **KernelSU Manager 3.3.1 / UAPI 5**。

用户已于 2026-11-10 验证 build 65 在 One UI 8.5 / Android 16 / `S9110ZCS8FZJ1`
上的 root 与重开首页状态。本版沿用该运行逻辑；build 67、One UI 9 和完整重启
回归没有新增真机验证。CI 重建驱动、ksud 和 APK，并校验版本、签名、载荷和附件摘要。

旧标签保留其原有工作流，修复不会追溯改写历史 CI；请勿重跑 0.3.0 及更早正式版
的旧发布任务。新流程从本版本开始生效。

## 安装

下载 **GhostSam-S23.apk**。当前 CI 每次构建生成 debug 签名；若提示签名冲突，
先保存需要的设置和日志，再卸载旧版、安装新版，并在 KSU 中重新授予 su 权限。
手机现有 root 可保留；首次使用或完整重启后再执行临时 root 流程。

附件包含 `GhostSam-S23.apk`、`BUILD-INFO.txt` 和 `SHA256SUMS`。
在下载目录执行 `sha256sum -c SHA256SUMS` 校验文件。
