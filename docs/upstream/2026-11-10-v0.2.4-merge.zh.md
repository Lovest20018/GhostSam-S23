# GhostSam v0.2.4 合并记录

合并日期：2026-11-10。上游目标：`8fa2f68c39119eeea46f059057fecc5f371ee427`。
本次把已审查的 v0.2.4 合入 S23 主线，保留上游 Git 历史。

## 采用的变化

- DirtyFrag core、loader、JNI 与 `android13-5.15` helper 成组更新。
- 移除上游已删除的 companion APK、安装流程与旧 DFR 路径。
- 保留上游其他机型的源码和资产更新，但 S23 APK 仍只打包选定的两个 payload。
- KernelSU 固定 `b086147e79e2725177d960e7161ba279288efc9d`，与新版 helper
  的 late-load 参数配套。新版 ksud 统一处理分区只读，不再依赖 helper 传入
  `--ro-partitions`。驱动和 ksud 继续从同一固定源码重建，只嵌入
  `android13-5.15_kernelsu.ko`。
- 新 KernelSU 原生包含 UAPI 5 和 Manager task_work 监听；旧回移补丁不再应用。
  构建改用 `CONFIG_KSU_RKP_NO_PATCH_TEXT`，并验证备用 hook 符号存在。

## 保留的 S23 定制

- 产品名 GhostSam S23、包名 `com.snothin.ghostsam.s23`，以及独立的
  `0.3.0-dev` / build 64。构建不自动递增 S23 版本号。
- 默认仅启用 DirtyFrag standalone 与官方 KernelSU Manager 3.3.1。
- 模块加载、应用 `su -c id` 授权与 Manager 身份保持分别判断；
  native 的 `kernelsu=up` 不再被当作应用已取得 uid 0 的证据。
- S23 首页状态、授权提示与独立中英文文案。
- 已移除固件编号和完整内核精确匹配；仍检查 SM-S9110、最低 SDK、KMI、
  内核窗口、页缓存探测及资产。One UI 9 不属于本次适配目标。
- 保留当前 S23 的 SDK/NDK 与发布策略；上游的版本自增只适用于显式通用构建。
